几个典型操作：

| 操作 | 命令 |
| --- | --- |
| 启动 agent | `agent` |
| 查看版本 | `agent -v` |
| 升级 | `agent update` |
| 查看历史 session | `agent ls` |
| 非交互启动 headless agent | `agent -p <prompt>` |

agent 启动后的交互命令：

| 操作 | 命令 |
| --- | --- |
| 切换 model | `/model` |
| 切换模式 | `/plan`、`/ask` |
| 执行 shell 命令 | `!` 后直接加命令 |

配置文件：`~/.cursor/cli-config.json` 和 `<project>/.cursor/cli.json`

关联资料：
